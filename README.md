# 六爻排盘 — 增删卜易 · 铜钱起卦

依据《增删卜易》全书体系的在线六爻排盘工具，支持铜钱起卦、直选起卦、在线摇卦三种模式。

## 功能特点

- **三种起卦模式**：铜钱翻转（手动选择）、直接下拉选爻、在线随机摇卦
- **完整排盘**：干支信息、卦名卦象、爻象表格、六神、纳甲（含天干）、六亲、旺衰、变卦纳甲六亲
- **神煞标注**：卦身、驿马、桃花、日禄
- **六冲六合**：卦级六冲/六合标注
- **用神分析**：自动推断用神、元神、忌神、仇神，含旺衰与十二长生
- **动变分析**：化进退神、化回头生克、化空破墓等动变标注
- **大白话解卦**：基于排盘数据给出通俗解读
